# Ekran görüntülerinin kaynağı

- `ui-1.12.0-world.jpg`, `ui-1.12.0-pack.jpg`, `ui-1.12.0-mobile.jpg` ve `ui-1.12.0-landscape.jpg`:
  1.12.0 geliştirme dalının yerel üretim Worker önizlemesinden, gerçek tarayıcıda
  alınan ekranlar. Canlı Cloudflare sürümünün görüntüsü olarak sunulmaz.
  Mobil görüntü masaüstü viewport denemesidir; fiziksel Android kanıtı değildir.
- `desktop.jpg`, `mobile.jpg` ve diğer eski ekranlar: tarihsel 1.3 dönemi
  referanslarıdır; güncel 1.12 veya tamamlanmış 2.0 görseli değildir.

Kaynak ekranlar yapay üretilmiş mockup değildir. Yeni bir sürümde yalnızca
gerçekten yeniden alınmış görüntüyü o sürümün ekranı olarak etiketle.
